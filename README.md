# Quill field for [MoonShine Laravel admin panel](https://moonshine-laravel.com)

### Requirements

- MoonShine v3.0+

### Support MoonShine versions

| MoonShine   | Quill |
|-------------|-------|
| 2.0+        | 2.0+  |
| 3.0+        | 3.0+  |


## Installation
```shell
composer require moonshine/quill
```

## Usage

```php
use MoonShine\Quill\Fields\Quill;

Quill::make('Label')
```
